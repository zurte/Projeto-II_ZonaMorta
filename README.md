# Zona Morta

Esse é um jogo que meu grupo fez no curso de T.i, na instituição Grau Tecnico.

## Como executar

O projeto ainda não tem um executaveu. Então para iniciar o jogo você precisa ir ate a pasta principal do jogo.
Quando ela estiver aberta, abra o terminal dentro desta pasta 

> shift + Botão direito no espaço vazio e escolha **abrir CMD aqui**

E digite 

~~~
Python main.py
~~~

ou 

~~~
Python3 main.py
~~~
