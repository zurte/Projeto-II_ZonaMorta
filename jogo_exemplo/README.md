# Jogo 'Coletar moedas' (pygame + placar no SQLite)

Mova a nave com as setas, pegue as moedas e fuja dos quadrados vermelhos. As regras ficam em `logica.py` (sem pygame).

## Como executar

```
pip install -r requirements.txt
python3 jogo.py
```

## Testes

```
python3 -m unittest discover -s tests
```
